## Stack
- Next.js 16 (App Router) + React 19 + TypeScript
- Tailwind CSS 4 + shadcn/ui para componentes
- better-auth para autenticação (login com Google)
- Orval para gerar clientes de API tipados
- Vercel AI SDK (useChat + DefaultChatTransport) para o chatbot
- nuqs para estado na URL
- dayjs para datas
- pnpm como package manager

## Comandos
- pnpm run dev — servidor de desenvolvimento (porta 3000)
- npx orval — regenerar funções de API após mudanças no backend (API precisa estar rodando na 8080)
- pnpm build — build de produção (deve passar sem erros)
