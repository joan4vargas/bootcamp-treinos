# Tarefa
Crie a tela de login e integre ela com a API.

# Requisitos Técnicos
- Seja 100% FIEL ao Figma em https://www.figma.com/design/icflmwVThvfpiYYXFId8gG/FIT.AI (tela "Login").
- Ao clicar em "Fazer login com Google", chame o authClient (app/_lib/auth-client.ts) com callbackURL = NEXT_PUBLIC_BASE_URL.
- Ao acessar a página inicial, caso o usuário não esteja autenticado, redirecione-o para /auth.
- Se o usuário já estiver autenticado e acessar /auth, redirecione-o para /.
